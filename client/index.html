📝 STUDENT REVISION NOTES

1. The Two Rooms:
• Stack: Personal study desk for fast local variables and method call trays (LIFO). Wiped in 0.001ms.
• Heap: Spacious shared warehouse for big objects created with new.

2. The TV Remote Secret:
• The variable is just a TV remote control dialed into an address (e.g. 0x4A2F).
• Dog d2 = dog; creates a second remote control tuned to the SAME television (Aliasing)!

3. Pass-by-Value:
• Java always copies the value on the desk.
• Passing an object copies the remote's address, never the television!
